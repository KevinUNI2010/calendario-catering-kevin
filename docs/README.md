# 📁 CARPETA DE ENTREGA TÉCNICA Y OPERATIVA (DOSSIER DEL PROYECTO)
## Sistema Web de Gestión de Calendario y Catering para Locales

Bienvenido al paquete formal de documentación del proyecto. Esta carpeta contiene los **5 documentos oficiales** requeridos para la presentación, validación técnica, capacitación operativa y cierre contractual con la empresa.

---

### 📑 ÍNDICE DE DOCUMENTOS DISPONIBLES

1. **[01. Ficha Técnica y Resumen Ejecutivo](01_FICHA_TECNICA_Y_RESUMEN_EJECUTIVO.md)**
   * *Dirigido a:* Gerencia General, Dirección Comercial y Finanzas.
   * *Contenido:* Objetivos cumplidos, justificación de valor para el negocio, arquitectura cloud de alto nivel y matriz de módulos del sistema.

2. **[02. Manual de Usuario y Guía de Operación](02_MANUAL_DE_USUARIO_Y_OPERACION.md)**
   * *Dirigido a:* Jefatura de Operaciones, Supervisores de Catering, Cocina y Encargados de Local.
   * *Contenido:* Guía visual paso a paso para el perfil Administrador (`/admin`) y perfil Cliente/Espectador con PIN (`/`). Instrucciones para el uso del **Resumen Mensual** de raciones de cocina.

3. **[03. Informe de Seguridad y Protección de Datos](03_INFORME_DE_SEGURIDAD_Y_PROTECCION_DE_DATOS.md)**
   * *Dirigido a:* Área de TI, Oficial de Seguridad de la Información y Auditores.
   * *Contenido:* Detalle de políticas Row Level Security (RLS) en PostgreSQL, autenticación segura con Google OAuth, procedimiento remoto `verify_client_pin`, bloqueo ante fuerza bruta y defensa en profundidad.

4. **[04. Plan de Soporte, Mantenimiento y Continuidad Operativa](04_PLAN_DE_SOPORTE_Y_CONTINUIDAD.md)**
   * *Dirigido a:* Operaciones, Soporte Técnico y Recursos Humanos.
   * *Contenido:* Políticas de copias de seguridad (backups automáticos), gestión ante rotación de personal (cambio ágil de PINs), niveles de servicio (SLA) y canales de atención.

5. **[05. Acta de Entrega y Conformidad del Proyecto](05_ACTA_DE_ENTREGA_Y_CONFORMIDAD.md)**
   * *Dirigido a:* Gerencia General, Operaciones y Responsable del Proyecto.
   * *Contenido:* Formato legal/institucional de aceptación formal con checklist de entregables y casillas de firma de conformidad.
